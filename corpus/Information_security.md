# Information security

Northstar Studio fictional policy. Owner: IT Operations. Version 2, effective September 1, 2026.

## Access requests
Request software access through the IT service desk. The system owner must approve access before IT provisions it. Use company-managed accounts and enable multifactor authentication.

## Security incidents
Report a lost device or suspected credential exposure to the IT service desk immediately. Do not post passwords, access tokens, or customer data in team channels.

## Approved tools
Use only approved systems for company records. Request a security review before introducing a new tool that stores customer information.
